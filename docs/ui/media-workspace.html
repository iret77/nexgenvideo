Media workspace and shared source pickers

  • Folders occupy the left sidebar, the library the central surface, and preview/details the right column. Hiding folders leaves the library usable. Folder navigation changes results, not the active source.
  • Folder actions reuse canonical IDs, import, move, rename and undo. A native parent drop area must not shadow inner folder targets.
  • Grid and list share asset selection, context actions, relink and drag payloads. Readable titles and original import filenames replace internal storage hashes.
  • Search covers names, transcripts, visual moments and current document bytes. Type/AI filters apply before result limits. Unsearchable documents are reported, never silently treated as complete search coverage.
  • Each workspace retains folder, filters, view, scroll position and source range. Each purpose-specific picker retains its own filter, selection and scroll state. Opening a picker does not seek or edit the timeline.
  • Production references, intake and generation slots use the same picker. Assignment occurs only through the calling action. “Show in Media” explicitly opens the same asset in the organizer.
  • The Edit browser is compact; folder administration stays in Media. Postproduction can preview originals without assigning or replacing a shot source.
