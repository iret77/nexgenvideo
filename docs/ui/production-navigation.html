  • Workflow selects an artifact without executing or approving it. Sources reuses the project media picker.
  • The center shows the selected phase artifact. The dock shows the current permitted action or the concrete missing prerequisite. Input and spend decisions remain fixed in the dock.
  • The inspector follows the selected storyboard shot, Bible object or other production object. Technical shot fields are readable details, not raw dictionary dumps in the shot grid.
  • AI activity opens a nonmodal flyout with actual running work, recovery and creative input. Budget and export have separate details.
  • Production has no timeline or empty film preview. Editing and playback belong to Cut and Postproduction.
  • The existing subject field is the prominent narrative; the secondary label is the shot purpose. This schema does not provide separate title and action fields, so none are invented. Section ranges are explicitly section timing. Per-shot timing, sketches, moments and Animatic remain deferred until their separate contracts are approved; no nonfunctional controls advertise them.
  • Artifact byte binding, shared gates, explicit rewind and exact pack pinning are unchanged.

Native acceptance

GitHub Actions captures the real editor at standard and enlarged text sizes. It checks three independent production columns, absent timeline/preview, phase selection, persistent status and dock, shot selection with inspector details, unchanged saved project bytes, and keyboard focus. Pipeline state, Briefing and a two-section Storyboard are captured next to the approved template for visual review.
