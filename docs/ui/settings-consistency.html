Settings, Help and provider consistency

Normative release specification for the Settings/Help shell, Agent runtime status and provider cards.

  • One window shell: Settings and Help use the same 980×640 default size, 760×480 minimum, 220-point opaque sidebar, page header, scroll insets and section rhythm.
  • One row for status and action: Claude Code’s status badge and Check again action share the runtime row. A separate action row exists only when an installation action is required.
  • One provider-card anatomy: every card has the same header and control-body minimum heights. Transport-specific content changes inside the body; the outer geometry does not.
  • Errors are intentional expansion: an error notice may add height below the standardized body. Normal states remain equal.
  • SwiftUI owns web authentication: OAuth uses EnvironmentValues.webAuthenticationSession. No manually retained presentation anchor, unsafe cross-actor AppKit object or callback-thread view mutation remains.
  • Atomic completion: after OAuth token exchange, the provider snapshot changes once and the catalog notification is emitted after the browser session has returned.
