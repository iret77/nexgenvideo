Settings: one layout, native model support

Current specification for all six Settings pages. This supersedes the Models capability-research surface. The native application uses AppTheme tokens; this standalone preview illustrates its information hierarchy.

  • Settings and Help retain the shared shell: 980×640 default, 760×480 minimum, 220-point sidebar, persistent page header and scrollable content. Content has a 760-point maximum width.
  • All setting rows use the same 16-point padding and gap. Descriptions wrap in the available label width. Control placement depends on available width and control size, never the intrinsic width of description text. Controls align to the trailing edge, including in a narrow stacked row.
  • Native supported models work from the shipped provider adapters, bundled profiles and validated discovery. Model support never requires a Claude session or accepting a research overlay. Unknown artistic capacities remain internal unknowns; they are not presented as an incomplete model installation.
  • Models starts with search and shows Image, Video, Audio and Upscaling groups from connected providers. Each row has a model name, provider names and an accessible visibility switch. Disabled visibility is retained across provider reconnects. Empty and no-match states are distinct.
  • Providers use a single column with one header and credential area per service. API key, OAuth and local connections retain their working controls. All controls and errors remain in the same card; credentials stay in Keychain.
  • Format Packs groups versions under their pack name. Remove targets the selected id and version, including directories returned by enumeration. Open-project use blocks removal; closed-project use is described before confirmation. Resident removal explains the restart. No project is silently repinned.
  • All pages inherit the shared button style. Disabled controls visibly lose active contrast and do not respond to hover. Functional labels remain visible.
  • Acceptance covers all six tabs at default and minimum size and 100%, 125%, 150% text scale. Native row tests assert actual control positions with short and long descriptions. Native pack tests use enumerated directories, preserve adjacent versions, and reject metadata replacement and symlink escape.
