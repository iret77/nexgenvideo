Home update notices

Home keeps its page title semantically pure. App and format-pack updates appear in one dedicated, actionable notice region between the title and project content.

Design principles

  • Title purity: “Welcome to NexGenVideo” contains no badges, warnings, update state, buttons, or changing content.
  • Context before chrome: a startup state that affects project creation belongs in the Home content hierarchy, not in the title, a tooltip, or a modal startup alert.
  • Status plus resolution: every notice names the state, explains its consequence, and presents a visible verb-led action in the same component.
  • Proportionate prominence: restart-required is persistent and warning-toned because stale resident pack code blocks new format projects. An available update is informative, not an error.
  • One canonical region: app updates and pack updates use the same notice anatomy; neither is appended to the page title.

Placement and hierarchy

  • The region uses the same leading and trailing inset as the page title and “My Projects”.
  • Order is title → notice stack when nonempty → “My Projects” → project grid.
  • When there is no update state, the notice region does not exist and reserves no blank space.
  • When multiple notices exist, blocking restart-required state appears first.

Notice anatomy

ElementRule
IconState symbol in a fixed leading frame; never the only explanation.
TitleSpecific state, one line where possible.
BodyOne calm sentence naming why the user should act or what is blocked.
ActionVisible text label. Restart uses “Restart NexGenVideo”; navigation uses “Open Format Packs…”; app installation uses “Install Update…”.
DismissalRestart-required is not dismissible while it blocks format-project creation. A nonblocking app update offers visible “Not Now”.

States

  • None: no notice and no reserved space.
  • Pack update available: informative notice; action opens Settings → Format Packs.
  • Pack restart required: warning notice; direct restart action.
  • App update available: informative notice; Install Update… and Not Now.
  • Combined: restart-required first, app update second.
  • Compact: below 800 points, actions move below the copy and align trailing; copy and actions never truncate or overlap.

Implementation constraints

  • SwiftUI uses only AppTheme spacing, type, radius, border, opacity, icon-size, background, text, status, and animation constants.
  • The notice action calls the existing canonical update/restart state machines; it does not duplicate pack lifecycle logic.
  • Settings’ right-aligned Format Packs attention icon remains a compact secondary route, not a substitute for this launch-critical action.

Acceptance criteria

  • No dynamic status view is a sibling of WelcomeTitle inside the title row.
  • Restart-required renders below the title with icon, title, consequence, and a visible “Restart NexGenVideo” button.
  • Pack update available renders below the title with a visible “Open Format Packs…” button.
  • No-update Home matches the existing hierarchy without a blank notice slot.
  • Normal and minimum Home widths preserve title, copy, and action without collision.
