Repeatable optional intake

Normative treatment for host-owned intake that can collect zero, one, or several named items, such as prepared characters and locations.

Rules

  • The card title names and numbers exactly one current item: Prepared character 1, Prepared character 2, and so on.
  • Files shown inside the card all belong to that one item. The additional-file action says Add another image…, never “Add another…” without an object.
  • The primary Attach action is enabled only when the item has both a usable name and at least one accepted reference image.
  • On the first empty item, a visible Skip action ends the entire optional step.
  • After one item was attached, the next empty item shows Done. It ends the repeatable step without creating an empty item.
  • Once the current item contains a name or reference image, completion and close stay disabled. A visible Clear item action resets that unsubmitted draft.
  • Disabled controls use the shared app-wide button treatment: muted text, non-accented background, reduced opacity, and no hover response.

Acceptance

  • At every repetition, the user can identify which item is being edited.
  • Clicking every visible control in every state cannot submit an unnamed or imageless item.
  • A user with zero prepared items and a user who has finished after N items both have an explicit labeled completion action.
