Direct source selection

  • Select an original medium or a timeline clip to activate its preview and inspector. Headers describe the object; there are no viewer mode controls or visible source tabs.
  • Remember each source's cursor, In/Out and target track. Timeline time remains independent. Search, type and folder filters affect only library results.
  • Accent marks the active area's selection; the other area's remembered selection is neutral. Context-click activates its target and preserves a selected group.
  • In/Out and Insert/Overwrite precede file metadata in Edit. Out is exclusive. Insert ripples; Overwrite replaces the target interval. Both are one undoable timeline edit.
  • Offline media cannot be inserted. Documents use native Quick Look with no temporal transport or source-range actions. Film-only overlays stay off source previews.
  • Source history is available in the preview's native context menu. Deleting the active medium activates a surviving preview; Undo restores the deleted source context.
