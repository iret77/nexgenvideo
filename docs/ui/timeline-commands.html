Timeline commands

Track header context menus name their target track in every command. Audio tracks expose Mute/Unmute, visual tracks Hide/Show; both expose Sync Lock/Unlock Sync. These actions use the existing header command methods and shared timeline Undo/Redo. Remove names the number of contained clips and is enabled only in Edit.

Opening or dismissing the menu does not mutate the timeline. Commands bind the track ID at menu creation and resolve it again at execution; a deleted target is a no-op. Empty header space and the ruler have no track menu. Removing a track rechecks the current Edit workspace at execution.

The mock illustrates menu content only. Native interaction, VoiceOver, undo and redo require Actions acceptance.
