Pipeline overview

  • Keep the canonical phase order, surface destinations and gate behavior.
  • Reserve equal columns for destination (76 pt), approval action (62 pt), status icon (28 pt) and menu (22 pt), including empty states. No phase has a generic status subtitle. A single right-column icon communicates Not started (empty circle), In progress (progress ring), Needs revision (warning triangle), or Approved (checked circle), with tooltip and accessible label. Concrete notes remain available on the status icon.
  • Use a minimum 40 pt row, subtle separators and a faint warm background for the current phase. Completed rows use one green checked circle in the status column; no duplicate left-hand status marker.
  • Below 380 pt panel width, put the same aligned action columns beneath the phase name. Phase names may wrap. Tab titles stay complete on one line; overflow scrolls horizontally, without hiding tabs.
  • Approval remains visible for the current phase, disabled until ready. The approval action is absent during execution; the separate status icon reports progress. Disabled controls retain shared disabled styling.
  • The header progress bar counts approved phases only. Detailed execution progress remains in the agent transcript.
  • Native styling uses AppTheme tokens. This HTML is a visual reference, not native runtime evidence.
