Pipeline overview

  • Keep the canonical phase order, surface destinations and gate behavior.
  • Reserve equal columns for destination (76 pt), approval/state (62 pt) and menu (22 pt), including empty states. Completed phases have no generic subtitle. Actual approval notes remain available on the approval icon; revision requests retain their visible subtitle.
  • Use a minimum 40 pt row, subtle separators and a faint warm background for the current phase. Completed rows use a green progress check and a quiet checkmark in the reserved approval column; never repeat “Approved” as row text.
  • Below 380 pt panel width, put the same aligned action columns beneath the phase name. Phase names and revision warnings may wrap. Tab titles stay complete on one line; overflow scrolls horizontally, without hiding tabs.
  • Approval remains visible for the current phase, disabled until ready. Running replaces approval during execution. Disabled controls retain shared disabled styling.
  • The header progress bar counts approved phases only. Detailed execution progress remains in the agent transcript.
  • Native styling uses AppTheme tokens. This HTML is a visual reference, not native runtime evidence.
