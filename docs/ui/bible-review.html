Bible: visual overview, source preview, object inspector

The Bible board owns entity names and reference-sheet thumbnails. Selecting an entity opens its details and existing edit, revision, usage and decision actions in the canonical Inspector. Full prompts and attribute lists appear once, in the Inspector; the board does not repeat them. Look remains readable in the Bible and its Inspector owns contextual decisions and navigation.

Selecting a sheet opens the exact project image in the existing Preview surface, labelled Reference Preview with entity and view. It preserves the entity as the inspected object, does not import another asset, mutate the film or move its playhead. An explicit Film Preview action returns to the timeline. Preview history uses the same back/forward/close controls as other sources.

Images resolve through the shared project-local file resolver, including pipeline-relative and project-home-relative paths. Disk I/O runs off the UI actor. Loading, unavailable and retry states are explicit. A project/revision/path change invalidates image state; canceled loads cannot publish stale images. Unavailable images never look like successful blank thumbnails and do not trigger paid regeneration.

Acceptance: populated Bible with pipeline-relative sheets, multiple entities/views, same-path image replacement, missing/corrupt files, project switching, reference-to-film navigation and readable narrow/scaled layouts. HTML is illustrative; native verification remains required.
