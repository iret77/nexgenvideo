# Preserved UI workbench snapshot

This archive preserves uncommitted UI concepts, scripts, review evidence, and images found in the NexGenVideo main worktree on 2026-09-24. The source files remain in place. This snapshot is unfinished historical work, not an approved product contract or runtime implementation. No current CI result validates it. Paths under `docs/ui/` reflect their original relative layout.

Local checkout paths and upstream repository references in text files were replaced with placeholders; image bytes were copied unchanged. The unchanged source is also kept in a local, Git-excluded archive. Browser profiles and cache data were deliberately excluded from Git and remain in the original worktree. See `manifest.json` for each original path and its source and archived SHA-256 hash.
