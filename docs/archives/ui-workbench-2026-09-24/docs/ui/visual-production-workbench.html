Review specification · implementation scope and limits

NexGenVideo: visual production workbench — review candidate

Supersedes the presentation proposal in production-workbench.html for this review, without changing native code or locked contracts. The earlier mockup remains preserved. Source-based self-review and Claude Fable 5.1 medium review are in review/.

  • Desktop editing workbench: continuous chrome, compact workflow navigator, dominant visual canvas, selection inspector, persistent approval/job/budget dock. No general chat composer. UI follows project pack palette; Music Video uses #D940A0. Use AppTheme tokens in native implementation.
  • Top-level workspaces: Preproduction, Edit, Finish. Render is the final Preproduction phase, not a second duplicate workspace. Canonical IDs remain project_init, analysis, brief, production_design, treatment, storyboard, bible, shotlist, sanity, frames, render; display References maps to bible, Production Check to sanity, Production Frames to frames. Generic workflow omits music analysis, and pack resolution must fail closed.
  • Audio retains existing BeatTimeline, StatRow, StructureHierarchyList, missing/unresolved/review-required states and measured provenance. Expand these with synchronized time selection; never fabricate measurements or let creative labels overwrite measured timing. Prototype data are illustrative, 20 seconds, 120 BPM. Optional phrases demonstrate available hierarchy only. Preview is silent timing, not playback of an absent file.
  • Brief, Design, Treatment open with supplied creative drafts and selectable visual concepts, then one scoped direction editor. Concept images are illustrative, not approved downstream artifacts. AI refinement is optional, previewed, accepted or declined and version-bound. Visual generation previews require actual new media; text replacement is never presented as a generated image.
  • Storyboard: sketches, shot identity, timing and silent animatic. Shot List: same records, production references and execution/source decisions. References: rendered identities and source provenance, never sketches. Native imported/AI-enhanced sources must bind actual project-local files. Mock source assignment is explicitly an example.
  • Blocking remains shot-list-owned plan/elevation and approved source binding. It is not a new 3D editor. Start-frame requirements exclude imported, AI-enhanced, reference-only and predecessor continuation/native extension routes. Native routes must come from the executable catalog and undergo exact lineage checks.
  • Approval readiness is deterministic; AI review advice does not set the gate. Native readiness comes from shared structural gates and exact-byte lineage; prototype readiness only validates its in-memory example. Approved edits require explicit rewind with downstream invalidation. Only one job runs; mutation and approval lock during the job. Output acceptance requires current revision and explicit take decisions. Cost authorization binds to the prepared job. Completed results survive cancellation and retry.
  • Music start: Track, optional Lyrics, Project Init, Audio Analysis approval, optional Story/Characters/Locations/Style, then Brief. Media import is never assignment. FilmFlow import stays optional and read-only preview here; no connector call or invented sync.
  • Upstream UI issues #506 continuous chrome, #507 contextual inspector/consistent controls, #508 media identity and provenance remain the scope; no non-UI upstream implementation is claimed.
  • Illustrative references reuse rendered concept studies, not authentic identity sheets. Provider/model/prompt provenance is absent and stated absent. Video jobs, take selection and export are simulated. No external API or persistent project mutation. Test fixtures reset a separate example. Plan images are distinct from colored concept renders.
  • Embedded root has explicit content height and no viewport-height cap. A standalone host may size the window independently. Preserve usable height in Codex embedding. Small layouts keep navigator, canvas, inspector and fixed workflow controls accessible.
