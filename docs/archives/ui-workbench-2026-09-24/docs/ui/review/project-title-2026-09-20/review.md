# Projektname ohne Dropdown

Das Projektmenü am Namen war nach Einführung der simulierten macOS-Menüleiste redundant. Es wurde einschließlich seiner Popup-Implementierung entfernt. Der Name ist reiner Text, ohne Pfeil, Hover-Aktion oder Tabstopp.

Neu, Öffnen, Sichern, Kopie sichern, Projekteinstellungen sowie Aufträge und Entscheidungen bleiben unter Ablage erreichbar. Der Abbruch eines Dialogs setzt den Fokus auf das Ablagemenü statt auf den entfernten Button.

54 vorhandene und angepasste Navigationsprüfungen bestanden. Darin sind der nicht interaktive Name und sämtliche Projektaktionen in allen fünf Arbeitsräumen, das Erstellen eines Projekts über Ablage sowie Tastatur- und Layoutprüfungen enthalten. Die gerenderte Medienansicht wurde visuell geprüft. Nachweise: checks.json und media.png in diesem Verzeichnis. Die native Anwendung wurde nicht geändert.
