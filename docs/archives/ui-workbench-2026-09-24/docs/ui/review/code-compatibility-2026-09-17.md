## Genuine concept deltas, not upstream or styling work

- **Script as an independent phase:** no canonical script phase/writer appears in the current locked harness phase table. Decide how to represent a lightweight scene/action artifact and its relation to existing Treatment/Storyboard. This is bounded contract work, not an already supported editor tab.
- **Shot requirements before rendered references:** current order is Bible → Shot List → Sanity → Frames. The target mock has Shot planning → References. Canonical Shot List validation already requires real references. Keep an explicit distinction between planning requirements and finalized media-bound execution inputs; do not reorder labels and assume the same writer will accept missing assets.
- **References combines identities and anchors:** useful common workspace, but native Bible and Frames remain different artifacts, owners and gates. A grouped workspace must expose their actual ordered state instead of one generic boolean.
- **Production Design omitted as a navigation step:** native writer/artifact remains necessary. First design its placement as scoped creative/visual controls; do not silently delete its data or capabilities.
- **Three workspaces:** native WorkspaceFocus has produce/edit/finish (`Editor/ViewModel/EditorViewModel.swift:59`). The current mock retains these three identities; Preproduction and Video-Takes live in Produce. Workspace switching is exclusively in the titlebar; sidebar content and selection are workspace-specific.
- **Structured interaction instead of chat:** reuse host dialogs and runner/gate surfaces; provide scoped direction, review and recovery capabilities before replacing the free-text entry point. Current mock does not demonstrate the full agent capability set.
- **FilmFlow shortcut:** explicit snapshot acceptance, stable identities, artifact writer ownership, imported lineage and pack prerequisites need an import/adoption contract. “Mark earlier steps approved” is not native-compatible. The mock's covered/imported distinction illustrates intent only; there is no live connector in this artifact.
- **#533 Pre-Render Review:** extend/connect existing chronology, storyboard bindings, state ladder, execution inputs, Sanity and image audits. New work is the integrated revision-bound review and filmmaker-facing correction flow; typed state dimensions, ambiguity/parallel-time handling and semantic coverage need targeted analysis. Do not promise full new engine construction or assume complete support merely because fields exist. The mock simulates one end-to-end finding/correction/rewind case; that fixture is not proof of native semantic coverage.
- **Simplified media routes:** the mock currently demonstrates generated/imported only, selected anchor inputs and placeholder videos. Native AI-enhanced, chaining/extension, role-aware Frames, provider availability and exact input proofs must remain supported; omission from the mock is not a removal decision.

## Corrections applied to the mock

Colored outer frame, active card/row borders, tab underlines and inspector/control rings are removed. Active selections use filled pack-accent surfaces; keyboard focus remains a contrasting neutral outline. Pack identity uses a filled label; primary action fills and meaningful chart marks retain accent color. Warning messages use text and a neutral divider rather than colored side rails. The comparison wipe is neutral.

The normative HTML spec links to this audit and explicitly distinguishes target UX from implemented native capability. The mock remains a proposal: it is not an implementation-complete spec for all native routes, accessibility states, inspector controls or #533.

## Follow-up: mode-specific media and multiple sketches per shot

- `Sources/NexGenVideo/MediaPanel/MediaPanelView.swift:7–31` already hosts Assets, Captions and Music. `MediaTab/MediaTab.swift:7–69` already has sorting, type/AI filters, search, thumbnails, folder/flat/grouped views and selection. The mock now exposes this existing library concept as a common media pool, with production/finish access and a default video browser in Edit. It does not imply removing existing captions, music, search or folder features.
- No second media database is proposed. A media selection changes source preview and inspector; it never assigns a project track, approves a phase or replaces a shot source. Import and workflow assignment remain separate. Concrete assignment controls appear only in the owning current phase.
- `Engine/Sources/NexGenEngine/Artifacts/Storyboard.swift:24–45`: `Step` has subject, camera, setup and blocking metadata, but no image collection with intra-shot offsets. Do not claim multiple sketches already work natively. A versioned mapping from storyboard step/planned-shot identity to ordered sketch assets, offsets and provenance needs deterministic validation and exact-byte lineage. Preserve the existing pack ABI; do not append stored fields to the public Step struct under a compatible pack contract.
- `SpatialProductionPlanV1.swift:183–207` already models internal generation time ranges, cuts and timed production references. Reuse its identity/time relationships where appropriate; its timedReferences are production inputs, not planning sketches. Sketches must never automatically become Render references.
- The mock fixture uses three separate prepared images for Shot 1E at 0.0 / 1.8 / 3.6 seconds of a 5-second uninterrupted shot. Animatic switches these images within the same shot; the next cut remains at the shared shot boundary. Changing shot duration scales the internal offsets. Adding a moment does not add a shot; missing imagery blocks storyboard approval. Generation is a prepared example for 1E, not a live or arbitrary image model.
- Actual UI changes remain bounded: route existing browser content by workspace, route media selection to existing inspector/source viewers, extend storyboard display to multiple image moments. New asset-binding contracts still require explicit native design before implementation.

## Follow-up: independent window controls

The mock removes the coupled Focus / Workspace / Inspector toggles. Small direct, mirrored sidebar icons independently control the two panes. The View dropdown is removed. Window commands share one compact titlebar: left sidebar switch, project-title menu and undo on the left; workspace selector centered; pack badge and Inspector switch on the right. The extra global toolbar row is removed. Long project names truncate without pushing controls away. Workflow / Media (Finish: Master / Media) are local sidebar tabs; their selection is idempotent, preserves pane width and does not replace the main canvas or inspector. Edit continues to host media and sequences in its own sidebar. Content undo preserves the current window arrangement and tab selection. Legacy saved focus states migrate to visible panes.

This is presentation state above the existing workspace and split-view machinery. No phase, provider, harness, pack ABI or native source was changed. The updated normative HTML spec describes the interaction contract.

## Follow-up: preserve the existing editing window

The revised clickdummy restores NGV's default Edit hierarchy: Media / Preview / Inspector above a full-width Timeline. It reuses the current code's toolbar, source/timeline transport and clip-inspector concepts. The native editor is the foundation, not a rewrite candidate. Ordinary trimming preserves adjacent clip positions; timeline instances remain separate from planned shots.
