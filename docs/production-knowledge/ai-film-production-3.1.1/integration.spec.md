## Delivery, not a summary

All 20 source Markdown documents are preserved as 254 independently addressable, exact-text sections. `units.json` additionally locates 631 blocks within those sections. `blueprints.json`, `procedures.json`, `tables.json` and `templates.json` expose the complete recipes, ordered runbooks, decision tables and fenced deliverables. The handbook presents the same full knowledge for a human/implementation agent, with Markdown whitespace normalized; exact original bytes are recoverable from the chapter JSON. Source material is packaged as knowledge data, not installed or invoked as a skill. No source repository, skill loader, network or external chapter lookup is required to read it.

The exact-text layer deliberately preserves exceptions, examples, rationale, evidence labels and numerical qualifiers. It is accompanied by NGV application contracts and precedence overrides; copying its imperatives wholesale into an agent system prompt would ignore those adaptations. Installation instructions are provenance-only. Provider/UI claims remain dated evidence. The decorative hero image is explicitly excluded; nothing actionable is excluded to fit a short initial library.

Content conservation proves that the extraction did not lose source text. The runtime ledger separately names each activation, consumer and verification rule. Dated provider claims remain evidence for a live route check rather than executable capability declarations.

## Record and selection contract

Every source section has a stable corpus ID for this source version, full hierarchical heading, complete content, source path/line range/commit/hash, application contract, local document references and integration status. Fine-grained unit offsets are Unicode code points into the section, end exclusive. They locate knowledge; they do not permit discarding adjacent qualifiers.

The runtime migration ledger must account for **every** inventory section and actionable subunit with a destination resource/entry, consumer, activation predicate, verification method, owner issue and status. A non-runtime disposition requires a specific reason (packaging metadata, historical evidence, duplicated navigation, explanatory source context, or future-pack-only specification). “Summarized elsewhere” is not enough when it drops an operative rule, template field, selector, exception or criterion.

Selection is by active phase, task, pack/profile, source mode, chosen genre/style, target model/version/operation and actual available capabilities. Load the applicable whole procedure/recipe plus its governing rules and scoped exceptions. Retain a lookup index for follow-up details. If the complete selected contract exceeds the context budget, stage retrieval across the task; do not truncate a runbook midway, drop Verify clauses, or inject the entire corpus globally. Context traces must identify the exact entry IDs/versions that shaped an artifact.

The selector must work in both Anthropic API and embedded CLI paths, on fresh start, resume and gate transition. The actual next phase's packaged instructions remain authoritative. An unrelated style, model or future format must not enter a musicvideo render prompt simply because it shares this corpus.

## Model rules that must not be flattened

- Separate technical attachment capacity from quality/stability budgets and distinct identities. Preserve the ≤8 default, 9–12 stretch/large-cast path, >5 single-view condition and video/audio selection guidance in their source scopes. Do not hardcode them as universal model API limits.
- Preserve one main action/one camera move, calm single-shot default, action/dialogue internal-cut planning and the scoped montage exception. A shot, a multi-shot take, a prompt revision and a returned result are separate objects.
- Keep the two permitted literal keyframe use cases distinct from a reference anchor; native video extension is a different operation and source binding. The accepted #485 contract preserves predecessor-last-frame chaining while treating approved reference anchors, two-state interpolation, frame continuation and native extension as distinct strategies.
- Draft at a diagnostic duration/tier is not the production take. Production is a new full-duration generation after beat lock; local production faults use supported scoped edits before wholesale regeneration.
- Negative instructions depend on model/channel and object/style/audio class. Preserve the two-failed-takes music-bleed exception and logged last-resort literal once; never turn it into repeated global negative prompting.
- H3 exact fields, Seedance mandatory blocks, Kling/Veo camera-first and Grok style-first stay separately selectable. Vendor/model version evidence is retained, not presented as freshly verified syntax.
- Canvas/aspect/grid in a still prompt has the explicit composition exception to “no double control”; video settings remain control-plane values except the documented inert-control/DoP cases.
- Budgets and iteration thresholds describe a diagnostic policy. Actual spend still needs the existing batch authorization and immutable request/result lineage.
